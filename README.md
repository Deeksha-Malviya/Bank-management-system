 🏦 Bank Management System

# About
A simple *Bank Management System* built using *Python* with data stored in *JSON* and a *Streamlit* interface.

# Project Order
1. `bank.py` – main backend logic  
2. `data.json` – stores user data  
3. `app.py` – Streamlit UI  

# Tech Used
Python, JSON, Streamlit

# Run
..bash
pip install streamlit
streamlit run app.py
